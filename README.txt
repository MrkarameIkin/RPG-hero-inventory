Интерфейс программы для работы с инвентарем Игрока

do while - Работает постоянно, пока игрок не нажмет Выход

1 - Добавить предмет - Игрок вводит название предмета, после чего этот предмет добавляется в конец списка инвентаря

2 - Инвентарь - Показывает пронумерованный список предметов инвентаря игрока
          Если название предметы повторяются, то рядом с ними будет написано их количество (х2, х3 итд)
    2.1 - Использовать предмет - Игрок вводит номер предмета, после чего тот "используется"
          (на экран выводится Предмет ххх был использован!, после чего он удаляется из списка)
    2.2 - Выбросить предмет - Игрок вводит номер предмета, который хочет удалить.
          - Игрок вводит номер предмета, после чего тот "выбрасывается"
          (на экран выводится Предмет ххх был выброшен!, после чего он удаляется из списка)
    2.3 - Очистить инвентарь - Система переспросит, точно ли игрок хочет очистить свой инвентарь. Если игрок ответит Да,
          то инвентарь удалится при помощи resize 0, если Нет, то окно свернется

3 - Выход - Завершает цикл при помощи break
