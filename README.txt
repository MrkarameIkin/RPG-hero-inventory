Интерфейс программы для работы с инвентарем Игрока

      do while - Работает постоянно, пока игрок не нажмет Выход
1   - Добавить предмет - Игрок вводит название предмета, после чего этот предмет добавляется в конец инвентаря
2   - Показать инвентарь - Показывает пронумерованный список предметов инвентаря игрока
      Если название предмета повторяется, то рядом с ним будет написано их количество (х2, х3 итд)
2.1 - Использовать предмет - Игрок вводит номер предмета, после чего тот "используется"
      (на экран выводится Предмет ххх был использован, после чего он удаляется из списка)
      Если предметов было несколько (х2, х3 итд), то количество предметов сократится на 1
      Если предмет остался один, то будет написано только его название, без х1
2.2 - Выбросить предмет - Игрок вводит номер предмета, который хочет удалить. Система переспросит, точно ли игрок
      хочет просто выбросить предмет. Если игрок ответит Да, то предмет просто удалится при помощи erase, если Нет,
      то окно свернется и снова выведется список предметов
2.3 - Очистить инвентарь - Система переспросит, точно ли игрок хочет очистить свой инвентарь. Если игрок ответит Да,
      то инвентарь удалится при помощи resize 0, если Нет, то окно свернется и снова выведется список предметов
3   - Выход - Завершает цикл при помощи break
